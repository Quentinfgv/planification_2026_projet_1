# 📊 Planification Projet Impulse - Site Web

## Description

Ce projet vise à créer un site web pour améliorer la visibilité d'Impulse, clarifier ses offres et générer des contacts. À long terme, le site devra devenir un outil de prospection grâce au SEO et renforcer l'image de marque.

## 📋 Livrables principaux

- Site vitrine optimisé SEO
- Pages offres claires
- Formulaires de contact et prise de rendez-vous
- Simulateur de partenariat
- Intégration des réseaux sociaux
- Espace administrateur
- Fiche Google Business

## ⏱️ Durée totale

**9 semaines** - Méthode en Cascade (Waterfall)

## 📁 Structure du projet

### Fichiers HTML interactifs

- **`index.html`** - Page d'accueil avec navigation vers les diagrammes
- **`gantt_interactif.html`** - Diagramme de Gantt interactif détaillé
- **`visualisation_schema.html`** - Schémas et diagrammes de flux du processus

### Documentation

- **`diagramme_gantt.md`** - Diagrammes de Gantt au format Mermaid
- **`schema_processus_cascade.md`** - Schémas complets du processus en cascade
- **`resume_processus.txt`** - Résumé textuel du processus

## 🚀 Utilisation

### Visualisation locale

1. Clonez le dépôt :
```bash
git clone https://github.com/Quentinfgv/planification_2026_projet_1.git
```

2. Ouvrez `index.html` dans votre navigateur pour accéder à la page d'accueil

3. Naviguez entre les différents diagrammes via les liens de navigation

### GitHub Pages

Le site est configuré pour être hébergé sur GitHub Pages. Accédez à :
- **Page d'accueil** : `https://quentinfgv.github.io/planification_2026_projet_1/`
- **Diagramme de Gantt** : `https://quentinfgv.github.io/planification_2026_projet_1/gantt_interactif.html`
- **Schémas Processus** : `https://quentinfgv.github.io/planification_2026_projet_1/visualisation_schema.html`

## 📊 Phases du projet

1. **Phase 1** : Cadrage et Analyse (1 semaine)
2. **Phase 2** : Conception UX (1 semaine)
3. **Phase 3** : Conception UI (1 semaine)
4. **Étape 3** : Analyse Système & Design (5 jours)
5. **Phase 4** : Développement (3 semaines)
6. **Phase 5** : Contenus & SEO (1 semaine)
7. **Phase 6** : Tests et Ajustements (1 semaine)
8. **Phase 7** : Mise en ligne (1 semaine)
9. **Étape 5** : Rendu Projet (4 jours)
